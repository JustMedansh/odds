# Personality Traits

| Trait | Low value | High value |
|---|---|---|
| Sociability | Prefers being alone | Seeks company |
| Assertiveness | Rarely takes charge | Naturally takes charge |
| Selflessness | Prioritises themselves | Prioritises others |
| Empathy | Less sensitive to others' feelings | Highly sensitive to others' feelings |
| Caution | Reckless | Careful |
| Impulsivity | Thinks before acting | Acts on impulse |
| Curiosity | Avoids the unknown | Seeks new experiences |
| Aggression | Avoids confrontation | More willing to confront |
